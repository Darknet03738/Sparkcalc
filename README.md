# Sparkcalc

Landing page para una plataforma de cálculo, análisis y gestión de proyectos eléctricos.

## Estructura

```text
.
├── index.html
├── sparkcalc.html
├── assets
│   ├── css
│   │   └── styles.css
│   └── js
│       └── main.js
└── README.md
```

## Desarrollo local

Este proyecto es una página estática. Puedes abrir `index.html` directamente en el navegador o publicarlo con GitHub Pages.

## Publicación en GitHub Pages

1. Sube el repositorio a GitHub.
2. Entra a `Settings > Pages`.
3. Selecciona la rama principal y la carpeta raíz.
4. Guarda los cambios y espera a que GitHub genere la URL pública.

# Sparkcalc

Landing page para una plataforma de cálculo, análisis y gestión de proyectos eléctricos.

```text
.
├── index.html
├── sparkcalc.html

│   ├── normativa.html
│   ├── planes.html
│   ├── proyectos.html

├── assets
│   ├── css

│       └── main.js
└── README.md
```

## Desarrollo local

Este proyecto es una página estática.

Las páginas dentro de `pages/` son prototipos navegables para validar estructura, contenido y flujo antes de conectar lógica real o backend.
